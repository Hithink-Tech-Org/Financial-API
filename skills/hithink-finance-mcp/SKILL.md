# hithink finance MCP

同花顺金融数据 MCP 的配置、工具选路与契约入口。按业务意图选择服务，进入业务文档中以目标 tool 名称标记的独立小节。当前连接返回的 `tools/list` 和 schema 决定可用工具及实际参数。

## 配置与连接

- 首次配置、认证或连接诊断：读取 [MCP 配置](references/mcp.md)；按宿主支持的配置位置和 Secret 机制设置服务。
- 使用在 <https://fuyao.aicubes.cn/admin/> 获取的 API Key，通过 `X-api-key` 请求头传递。先复用用户级 `HITHINK_FINANCE_API_KEY` 或受限凭据文件，详见 [认证与恢复](references/authentication.md)。
- 已连接时只检查当前任务需要的服务。工具未出现在实时清单时，报告当前可用范围；静态文档和配置文件不能代替连接验证。

## 工具路由

| 用户意图 | 业务域与工具目录 |
| --- | --- |
| 名称、ticker、证券代码消歧；代码表与交易日程 | [公共基础数据](references/mcp/meta/README.md) |
| A 股价格、历史行情、公司行动、财报、估值、集合竞价、异动、榜单与 A 股新股 | [A 股](references/mcp/a-share/README.md) |
| 港股新股递表、认购、上市日历与发行详情 | [港股新股](references/mcp/hk-share/README.md) |
| 指数、概念与行业板块目录、成分股和行情 | [指数与板块](references/mcp/index/README.md) |
| 基金档案、公司和经理、持仓、净值、收益、基金财务、资讯、回测、指标、QDII 额度及 ETF/LOF 行情 | [公募基金](references/mcp/fund/README.md) |
| 期货品种、合约、持仓、仓单、基差、交易时段、日程与行情 | [期货](references/mcp/futures/README.md) |
| 期权品种、合约、交易时段与行情 | [期权](references/mcp/options/README.md) |
| 资讯详情、快讯、公告解读、专题、异动解读与个股分时新闻 | [资讯](references/mcp/news/README.md) |

1. 仅查询工具说明时，读取对应目录，按链接锚点定位业务文档中的目标 tool 小节。
2. 实际取数时，用户只给名称或不完整代码，先用公共基础数据域的 `get_meta_tickers_search` 消歧为唯一 `thscode`。
3. 在目标业务域选择 tool，读取该工具小节中的用途、入参、默认值、时间窗口、分页、返回字段和关联结构；同页其它工具按需读取。
4. 按实时工具 schema 构造参数，执行调用并检查业务信封 `code=0`。确认结果中的标的、数据时间、口径、行数与分页范围。
5. 只返回摘要；全市场、分页全集、多标的或长序列结果落盘，交付路径、行数、窗口与来源。

## 调用规则

- 使用完整 `thscode`；身份不唯一时继续消歧，保留响应中的空代码、原记录和分页信息。
- 最新快照和财报不追问复权；历史行情按目标 tool 的复权和窗口契约执行。
- 时间戳、单位、日期与游标按工具契约传递；长整数标识使用字符串，`null`、零值、负数和空数组保持原义。
- 批量上限、共享条件、合法空组和无效标的处理逐 tool 核对，不用循环逐个请求冒充原生批量能力。
- 认证检查使用一个有界请求。认证失效时检查 Secret 注入和已有 Key 来源，更新后重连目标服务；参数、限流和上游错误按具体错误处理，避免无界重试。
- 真实数据不可用时报告失败阶段和脱敏错误，不用模拟数据替代。说明实际完成的验证范围。
- 端内专用能力按目录标记处理；以实时工具清单确认当前可调用范围。

配置与全部业务域索引见 [MCP 接入](references/mcp.md) 和 [工具目录](references/mcp/README.md)。
