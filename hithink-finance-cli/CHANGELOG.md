# Changelog

## Unreleased

## 0.2.4 - 2026-11-12

- WorkBuddy 等待 OAuth 登录完成后检查状态，避免提前终止本地回调任务。
- 前台授权在取消、父进程断开及正常终止信号后清理本次任务；保留后台模式的独立运行及强杀后的重新登录能力。
- 连接器版本可独立于 CLI 最低版本更新，安装继续使用国内镜像优先、官方源备用及 latest。
- WorkBuddy 托管 Node 22，以兼容 macOS 13.4 等满足 CLI 要求的系统。
- Windows 凭据检查直接使用系统安全 API，减少模块加载与账号名称解析，兼容繁忙环境下的初始化延迟。

## 0.2.3 - 2026-11-12

- Windows 登录兼容系统和管理员所有者、安全继承及正常读写权限，减少首次授权的环境限制。
- macOS/Linux 兼容合法 root 与可搜索目录；管理员写入用户目录后保留普通用户的访问能力。
- 后台登录保留本地存储错误的分类和退出码，提示检查存储而非反复重新登录。
- 修正跨平台验证中的进程保活与 Unix socket 临时路径，完善自动发布检查。

## 0.2.0 - 2026-11-04

- 系统用户目录不可用时，远端命令回退普通执行路径，显式 stdin API Key 仍可完成请求。
- 内置 Skills 的 description 承担业务首选路由，shared 提供辅助选路；接入 Skill 聚焦首次安装和 REST/MCP，CLI 的执行约束由包内文档维护。
- 统一 Skill、CLI 配套 Skills 与安装指引默认推荐 OAuth，复用当前有效凭据；补齐新股、资讯路由和认证状态退出码说明。
- `auth status` 已连接时退出 0，未连接时退出 3，stdout 保留结构化连接状态；WorkBuddy 连接器增加 CLI 最低版本检查。
- 配套 Skills 从 CLI 包发布到用户级共享目录，再链接到选定 Agent；移除第三方 Skills 安装工具依赖，修复托管链接切换复制模式的冲突。
- 包主页、安装和支持指引使用官网及 npm；发布流程采用维护者交互认证。

- 新增 A 股、指数、ETF 历史行情和三大财务报表的六个批量命令，每批最多 10 个原始代码，保留按代码分组的记录与合法空组并支持完整落盘；原基金快照命令支持最多 100 个代码的 CSV 输入并返回平铺报价。

- 新建 OAuth 登录不再探测旧系统凭据库；旧 Key 仍可显式迁移，普通业务首次导入保持原行为。

- 数据授权切换为扶摇金融数据读取权限；服务配置更新后，旧授权状态提示重新登录。

- 补充基础账号权限下的纯 OAuth 授权、续期及服务端用户身份整链验证。

- 收敛认证默认输出与进度，存储诊断通过 `--debug` 获取；网络错误提示适用于两种登录方式。

- 认证统一为用户级私有权限文件，旧凭据一次性迁入；同一请求复用凭据快照，减少 Windows 重复检查。
- 认证命令与进度补齐中文指引；成功回调页展示中文结果并在三秒后前往官网。

- 新增用户级全局认证状态、API Key 验证登录、一次性迁移、认证方式选择与只读状态。
- 新增 OAuth PKCE/OIDC、后台回调和安全续期实现；服务配置与实际环境验收待完成。
- OAuth 业务授权支持无 ID Token 登录，启用前验证数据服务访问；请求 OIDC 时保持严格身份校验。
- 合并重复的认证状态读取与已有锁权限检查，缩短 Windows 登录启动时间；资源验证网络错误明确区分于网页授权失败。
- 环境 Key 改为初始化时导入一次；日常 profile 改用全局选择。共享副本需一起升级。
- Node.js 支持范围调整为 `^22.13.0 || >=24.0.0`。
- 将 Zod 升级至 4.6.6，修复集合校验的资源耗尽风险。
